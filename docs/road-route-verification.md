- 전체 결과를 기본 600초/최대 64건 캐싱합니다. TTL·조건 변경·이미 지난 출발시각·깊은 복사·크기 제한을 단위 테스트했습니다. 같은 조건 재조회는 외부 API를 다시 호출하지 않습니다. 서버 재시작·다중 프로세스에서는 별도 캐시이며 동시 최초 요청 중복은 막지 않습니다.
- 현재 포트는 8003으로 유지했습니다. HTTP 실조회에서 첫 MISS/두 번째 HIT와 같은 상세 좌표를 확인했습니다. 브라우저에서 실제 추천·최단거리 카드, 거리·시간·출발/도착 마커와 카카오 지도 표시를 확인했습니다. 카드 전환 시각 검증은 사용자 브라우저 조작으로 중단됐으며 모바일과 도로 타일 위 선 모양 전체 비교는 완료하지 못했습니다. 실제 상세 좌표/API 응답 검증과 시각 확인 범위를 구분합니다.

# 상세 도로 경로 연결 검증 (2026-11-06)

변경 전에는 프론트 USE_MOCK=true로 routes.json의 네 점을 그렸고, 백엔드는 미래 길찾기 응답의 소요시간만 반환했다. 변경 후에는 기존 KakaoRouteProvider의 인증·오류 처리와 DepartureSolver를 재사용하며, 각 우선순위의 최종 상세 응답에서 도로 좌표·거리·소요시간을 함께 추출한다.

## 실제 외부 API 확인

서버 .env의 REST 키로 장소 검색과 미래 길찾기를 호출했다. 키는 출력하지 않았다. 도착 희망 시각은 검사 다음 날 09:00, 여유 10분이었다.

| 조회 구간 | 반환 카드 | 상세 좌표 수 | 거리 | 소요시간 |
| --- | --- | --- | --- | --- |
| 김해시청 → 동의대학교 가야캠퍼스 | 추천 | 260 | 22.727 km | 28분 |
| 같은 구간 | 최단거리 | 277 | 19.954 km | 35분 |
| 김해국제공항 국내선청사 → 부산역 | 추천 | 255 | 19.435 km | 28분 |
| 같은 구간 | 최단시간 | 265 | 19.878 km | 28분 |
| 같은 구간 | 최단거리 | 227 | 15.554 km | 29분 |

첫 구간의 추천/최단시간 경로가 같아 중복 제거했다. 결과 수와 시간·거리는 이후 조회 시 달라질 수 있다. 위 두 구간 검사에 장소 검색 포함 외부 요청 24회를 사용했다. `backend/scripts/check_road_routes.py`로 다시 검증할 수 있다.

카카오 장소 검색에서 ‘동의대학교’는 가야/양정 캠퍼스 등 여러 결과로 나온다. 사용자가 검색 목록에서 선택한 장소의 좌표를 fromLat/fromLng/toLat/toLng로 전달한다. 재입력 시 선택 좌표를 무효화하며 교환과 조건 수정에서는 함께 복원한다. 좌표 없는 이전 링크는 이름/주소를 하나로 확정할 수 있을 때만 조회한다.

## 자동 검증

- 상세 좌표의 경도/위도 변환, 여러 section/road 순서, 연속 중복 제거, 불완전·비정상 좌표 거부
- 같은 카드의 상세 응답과 거리·시간 일치, 우선순위별 경로 분리, 같은 경로 중복 제거
- 선택 좌표 사용, 좌표 범위/부분 쌍 거부, 모호한 장소 거부, 인증 실패 시 목업 미반환
- 기존 출발시각 엔진과 SDK 오류 처리·검색 기능 회귀

## 실행 및 남은 시각 검증

프론트와 백엔드를 동일한 `http://127.0.0.1:8003`에서 제공한다. 브라우저가 실제 `/api/routes`를 요청해 HTTP 200 응답을 받은 것을 서버 로그에서 확인했다. 브라우저 자동화의 DOM 연결 오류로 자동 시각 검증은 제한되었지만, 사용자가 같은 화면에서 ‘도로를 따라가는 경로선이 보여’라고 실제 표시를 확인했다. 모바일 화면과 모든 카드의 시각 비교는 별도로 확인하지 않았다.

백엔드 자동 테스트는 기존 엔진을 포함해 159개 통과했고, 기본 실행에서 기존 실조회 테스트 3개는 제외했다. 별도 수동 검사 스크립트로 위 두 구간을 실제 조회했다. 프론트 routes/map/search 회귀 테스트도 통과했다.

실행 명령과 모드 전환은 루트 README 및 backend/README를 참고한다. 실제 모드는 USE_MOCK=false, 서버 실행 시 ROUTE_PROVIDER=kakao다. REST 키는 .env에서만 읽고, 지도 배경용 JavaScript 키는 기존 프론트 설정을 유지한다.
